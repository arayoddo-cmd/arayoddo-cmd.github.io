# 🚀 태양계 탐사대: 행성의 비밀을 찾아라

학생이 탐사대원이 되어 태양계 8개 행성을 탐사하는 웹 활동이에요. 탐사 장비로 실제 사진과 데이터를 살펴보며 행성의 특징을 스스로 찾고, 여러 기준으로 행성을 나눠 보면서 **지구형 행성 / 목성형 행성** 개념에 도달해요. 마지막에는 퀴즈 게임으로 배운 내용을 복습해요.

## 활동 흐름

1. **대원 등록**: 학번과 이름을 입력해요.
2. **임무 1. 행성 탐사 (8개, 순서 자유)**
   - 탐사 장비 6개로 증거를 모아요.
     - 📷 표면 카메라: NASA 실제 사진과 관측 기록
     - 🌫️ 대기 분석기
     - 🌡️ 온도계
     - 📏 크기·거리 측정기
     - 🛰️ 위성·고리 탐지기: 위성 실제 사진
     - 🌀 자전 관측기: 지구와 나란히 자전하는 애니메이션 (수성·금성은 실제로는 아주 느려서, 돌아가는 모습이 보이도록 빠르게 보여 주고 화면에 안내해요)
   - **탐사 보고서** 빈칸을 채워요. 빈칸은 학습지와 같아요. 틀리면 어떤 장비를 다시 봐야 하는지 알려줘요.
   - **탐구 질문**("왜 그럴까?")을 맞히면 탐사 완료 🏅
3. **임무 2. 행성 분류 실험실**
   - 크기(반지름), 질량, 위성 수, 고리, 표면, 이렇게 **5가지 기준**마다 조건이 2개인 칸이 나와요. 행성 카드를 **끌어서** 알맞은 칸에 놓아요. 카드를 누른 다음 칸을 눌러도 돼요. 틀린 행성은 빨간 테두리로 표시돼요.
   - 결과 표를 보고 "기준이 바뀌어도 항상 같은 두 무리로 나뉜다"는 결론을 골라요.
   - 지구형/목성형 **비교표의 빈칸을 특징 카드로 직접 채워요.** 틀린 칸에 놓으면 카드가 돌아와요.
   - 정리 카드와 외우기 팁을 보고 확인 문제 10개를 풀어요.
4. **임무 3. 복습 퀴즈 대모험**: 한 판에 15문제(나는 누구일까?, O/X, 무리 나누기, 사진 퀴즈)가 나와요. 연속으로 맞히면 보너스 점수가 붙고, 도전할 때마다 문제가 새로 섞여요.
5. **탐사 완료 인증서**: 임무별 점수와 행성별 결과가 나와요. 공용 기기를 위한 '기록 지우기' 버튼도 있어요.
6. **보너스. 행성 알까기**: 자기 행성을 뒤로 당겼다 놓아 상대 행성을 판 밖으로 밀어내요. 컴퓨터와 대결하거나, 한 기기에서 친구와 번갈아 할 수 있어요.
   - **드래프트**: 8개 행성을 1-2-2-2-1 순서로 번갈아 골라 4개씩 팀을 만들어요. 카드마다 크기·질량·속도 막대와 실제 질량이 나와서 고르면서 비교하게 돼요. 컴퓨터도 "가장 무거워서 잘 밀리지 않거든요!"처럼 이유를 말하며 골라요.
   - **질량 점수**: 밀려난 행성의 질량 순서만큼 상대가 점수를 얻어요. (수성·화성 1, 금성·지구 2, 천왕성 3, 해왕성 4, 토성 5, 목성 6) 각 팀 6번씩 쏘고 점수가 높은 팀이 이겨요. 무거운 행성은 잘 안 밀리지만 밀려나면 크게 잃어서, 무거운 것만 고르는 게 정답이 아니에요.
   - **경기 후 정리**: 각 팀이 고른 행성, 지구형·목성형 구성, 총 질량을 표로 보여 줘요.
   - **3단계 블랙홀**: 점선 원 안을 지나가면 중력 때문에 길이 휘어요(빠르게 옆을 지나가도 약 20°). 가운데에 닿으면 빨려 들어가 밀려난 것으로 쳐요. 무겁든 가볍든 똑같이 끌려가요.
   - **균형**: 컴퓨터끼리 단계마다 150~200판씩 대결시켜 승률이 거의 반반이 되도록 맞췄어요. (각 팀 6번씩 쏘고, 1·2단계는 먼저 고른 팀이, 3단계는 나중에 고른 팀이 먼저 쏴요)
   - **클래식 모드**: 예전의 '지구형 팀 vs 목성형 팀' 전멸전도 남겨 두었어요. 무거운 목성형 팀이 더 유리해요.
   - **3단계**: 1단계 연습 궤도(장애물 없음) → 2단계 소행성대(소행성 장애물) → 3단계 블랙홀(가까이 가면 끌려가 빨려 들어감 + 소행성). 앞 단계에서 컴퓨터를 이기면 다음 단계가 열리고, 단계가 오를수록 컴퓨터의 조준도 정확해져요.
   - **실제 크기·질량 반영**: 판 위 행성 크기는 실제 지름에 따라, 무게는 실제 질량에 따라 달라요. 같은 힘으로 튕겨도 무거운 행성은 덜 날아가고, 부딪히면 무거운 행성이 가벼운 행성을 더 세게 밀어내요. 실제 질량 차이(목성은 수성의 약 5,800배)를 그대로 쓰면 게임이 되지 않아서, 차이를 줄여서 반영했어요(약 6배).

진행 상황은 학생 브라우저에 저장돼서 창을 닫았다 열어도 이어서 할 수 있어요.

## 결과 받는 방법

### A. 인증서 캡처 (설정 필요 없음)
학생이 마지막 인증서 화면을 캡처해서 클래스룸, 패들렛 등에 올려요.

### B. 구글 시트로 자동 수집 (약 10분, 처음 한 번만)

전체 흐름: **구글 시트 만들기 → 코드 붙여 넣기 → 시험 실행(권한 승인) → 웹 앱으로 배포 → 주소를 게임에 넣기 → 시험 제출**

**1단계. 구글 시트 만들기**
1. 학교 구글 계정으로 로그인한 뒤 [sheets.new](https://sheets.new)에 들어가요. 새 시트가 바로 열려요.
2. 왼쪽 위 '제목 없는 스프레드시트'를 눌러 이름을 바꿔요. (예: `태양계 탐사대 결과`)

**2단계. 코드 붙여 넣기**
1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요. 새 탭에 코드 편집기가 열려요.
2. 편집기에 있는 `function myFunction() { }`을 모두 지워요.
3. `apps-script.gs` 파일을 메모장으로 열어 내용을 **전부 복사**해서 붙여 넣어요.
4. 6번째 줄 `const CLASS_CODE = '여기에-수업코드';`에서 따옴표 안을 원하는 수업 코드로 바꿔요. (예: `'saturn7'`)
   - 따옴표(`'`)는 지우지 마세요.
   - 수업 코드는 학생들에게 칠판으로 알려줄 비밀번호 같은 거예요. 아무나 결과를 보내지 못하게 막아 줘요.
5. 위쪽 💾(프로젝트 저장)을 눌러요.

**3단계. 시험 실행하고 권한 승인하기**
1. 편집기 위쪽 함수 선택 칸(▶실행 버튼 오른쪽)에서 **`testWrite`**를 골라요.
2. **▶ 실행**을 눌러요.
3. '승인 필요' 창이 뜨면 **권한 검토** → 내 계정 선택을 눌러요.
4. **"Google에서 확인하지 않은 앱"** 경고가 나오면 왼쪽 아래 **고급** → **'(프로젝트 이름)(으)로 이동(안전하지 않음)'** → **허용**을 눌러요.
   - 내가 직접 만든 스크립트라서 나오는 경고예요. 이 스크립트는 이 시트에 줄을 추가하는 일만 해요.
5. 시트 탭으로 돌아가면 아래쪽에 **'탐사 결과'** 탭이 생기고, 시험 줄이 하나 들어가 있어요. (확인 후 지워도 돼요)

**4단계. 웹 앱으로 배포하기**
1. 편집기 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. '유형 선택' 옆 ⚙️(톱니바퀴) → **웹 앱**을 골라요.
3. 다음과 같이 설정해요.
   - 설명: 아무거나 (예: `탐사대 1`)
   - 다음 사용자 인증 정보로 실행: **나(내 이메일)**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/……/exec`)을 **복사**해요.
5. 확인: 복사한 주소를 브라우저 주소창에 붙여 넣으면 **"✅ 태양계 탐사대 결과 수집기가 작동 중이에요"**라는 문구가 보여야 해요.

**5단계. 게임에 주소 넣기**
1. `index.html`을 메모장으로 열어요. (파일 우클릭 → 연결 프로그램 → 메모장)
2. 위쪽에서 `SUBMIT_URL: ''` 줄을 찾아요. (Ctrl+F로 `SUBMIT_URL` 검색)
3. 따옴표 사이에 복사한 주소를 붙여 넣어요. 예: `SUBMIT_URL: 'https://script.google.com/macros/s/AKfy……/exec'`
4. 저장하고, GitHub에 다시 올려요. (Claude에게 주소를 알려 주면 대신 넣고 올려 줄 수 있어요)

**6단계. 시험 제출하기**
1. 게임을 열고 대원 등록에서 **학번에 `00000`**, 이름에 아무거나 넣고 시작해요. 시험 모드라서 바로 인증서 화면으로 가요.
2. 수업 코드를 넣고 **제출**을 눌러요. "✔ 제출되었어요"가 나오면 성공이에요.
3. 구글 시트 '탐사 결과' 탭에 새 줄이 생겼는지 확인해요.

**수업할 때**
- 학생들에게 게임 주소와 **수업 코드**를 알려줘요. 학생은 대원 등록 화면에서 학번·이름·수업 코드를 넣고 시작해요.
- 학생이 임무를 마칠 때마다 진행 상황이 자동으로 시트 **'탐사 현황'** 탭에 저장돼요. 학생 한 명당 한 줄이고, 진행할수록 그 줄이 바뀌어요.
- 결과는 시트를 열지 않아도 **게임 첫 화면 → 👩‍🏫 교사용 → 교사 코드(`TEACHER_CODE`)**로 볼 수 있어요. 기본은 임무별 완료 여부이고, **📊 세부 성적 보기**를 누르면 점수가 한꺼번에 보여요.
- 예전 버전에서 쓰던 '탐사 결과' 탭은 그대로 남아 있어요. 필요 없으면 지워도 돼요.

**문제가 생기면**

| 증상 | 해결 |
|---|---|
| "수업 코드가 맞지 않아요" | 학생이 입력한 코드와 `CLASS_CODE`가 같은지 확인해요. 대소문자와 띄어쓰기도 같아야 해요. |
| 액세스 권한에 '모든 사용자'가 없음 | 학교 관리자가 외부 공개를 막아 둔 경우예요. 이때는 학생들도 **같은 학교 계정으로 로그인**해야 제출할 수 있어요. 어렵다면 개인 구글 계정으로 시트를 만들거나, 인증서 캡처 방식(A)을 쓰세요. |
| "인터넷 연결을 확인해 주세요" | `SUBMIT_URL` 주소가 `/exec`로 끝나는지, 앞뒤 따옴표가 맞는지 확인해요. 주소를 브라우저에 넣었을 때 ✅ 문구가 나와야 해요. |
| 코드를 고쳤는데 반영이 안 됨 | Apps Script는 고친 뒤 **배포 → 배포 관리 → ✏️(수정) → 버전: 새 버전 → 배포**를 해야 반영돼요. 이렇게 하면 웹 앱 주소는 바뀌지 않아요. ('새 배포'를 누르면 주소가 바뀌니 주의!) |
| 반이 바뀌어 수업 코드를 바꾸고 싶음 | `CLASS_CODE`를 바꾸고 저장한 뒤, 위의 '새 버전' 방법으로 다시 배포해요. |

> 학생 이름과 점수는 선생님 구글 시트에만 저장되고, GitHub(공개 저장소)에는 저장되지 않아요. 시트는 다른 사람에게 공유하지 마세요.
> GitHub에 올리는 `apps-script.gs`에는 실제 수업 코드와 교사 코드를 넣지 마세요. 실제 코드는 Apps Script 편집기에만 넣어요.

## 참고

- 수치(지름, 질량, 온도 등)는 중학교 수준에 맞춰 반올림했어요. 위성 수는 새로 발견될 때마다 바뀌어서 '○개 이상'으로 표시했어요.
- 밀도는 아직 배우지 않은 개념이라 넣지 않았어요. 토성은 "물에 뜰 만큼 가볍다"는 표현을 썼어요.
- 정답이 페이지 코드 안에 들어 있어서 평가용으로는 적합하지 않아요. 탐구·복습 활동용으로 써 주세요.
